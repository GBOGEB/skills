# Method-specific visual map

| Topic | Canonical visuals | Strong supplemental visuals |
|---|---|---|
| PCA | scree, cumulative variance, PC1-PC2 scores, loading plot/biplot | PC1-PC3 scores/loadings, correlation circle, bootstrap loading intervals, eigengap, principal-angle trajectory, Procrustes displacement, Grassmann/projection distance, eigenvalue-time surface |
| Bradley-Terry | strength/probability plot, pairwise probability matrix | comparison network, CI/credible forest, residual matrix, temporal strength paths, rank/probability uncertainty |
| Confidence intervals | estimate+interval/forest | coverage plot, interval-width vs n, bootstrap distribution, profile likelihood, confidence sequence |
| Eigen/spectral | spectrum/stem, eigengap | Gershgorin discs, Rayleigh surface, pseudospectrum heatmap, eigenvector orientation, perturbation path |
| Matrix math | matrix heatmap, singular-value spectrum | sparsity pattern, condition trace, animated basis transformation, low-rank reconstruction error |
| ANOVA | group box/violin with means/intervals | interaction plot, residual diagnostics, effect-size forest, marginal means, sums-of-squares waterfall |
| Covariance/multivariate | covariance/correlation heatmap | covariance ellipse/ellipsoid, precision matrix, CCA/loadings, manifold-distance plot |
| Regression/GLM | observed+fit line/surface | residual-vs-fitted, QQ, leverage/Cook, coefficient forest, regularization path, partial dependence |
| Inference | effect+CI or null/reference distribution | p-value function, power curve, permutation null, FDR/equivalence/sequential boundaries |
| Multivariate inference | discriminant/canonical score space | confidence ellipse/ellipsoid, MANOVA statistic views, class boundary |
| Time series/state space | time trace with state estimate | ACF/PACF, spectrum/spectrogram, change-points, lag heatmap, state uncertainty ribbon |
| Calculus/dynamics | function/derivative/integral or trajectory | vector field, phase portrait, bifurcation diagram, Lyapunov trace, sensitivity surface |
| Monte Carlo/resampling | output histogram/ECDF | convergence trace, bootstrap cloud, rare-event tail, uncertainty decomposition, response surface |
| Information theory | MI/entropy heatmap | dependency network, conditional-MI map, redundancy/synergy diagram, transfer-entropy directed graph |
| Optimization/numerics | objective contour/surface + path | convergence/gradient trace, Hessian spectrum, regularization path, Pareto front, trust-region path |
| Probability/Bayesian | distribution/posterior | prior-likelihood-posterior, posterior predictive, trace/rank plots, calibration, credible region |
| Asymptotics/regime maps | regime/phase map | threshold bands, p/n-condition-effective-rank surfaces, MP/BBP boundary, finite-vs-asymptotic discrepancy |
